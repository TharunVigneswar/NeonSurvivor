# NEON SURVIVOR

Welcome to **NEON SURVIVOR**, a neon arcade survival game where your only goal is to survive the arena!

Enter a dark, futuristic arena, face endless waves of hostile enemies, and see how long you can last.

## About the Game

NEON SURVIVOR is a fast-paced survival shooter built using Python and Pygame. Enemies spawn around the arena and chase you relentlessly. Your job is to move, aim, shoot, and eliminate as many enemies as possible before your health runs out.

The longer you survive, the more challenging the arena becomes!

Your goal is simple: **Survive the arena. Eliminate the threat. Beat your high score!**

## Requirements

There are two ways to play NEON SURVIVOR:

- **Executable version:** Download the `.exe` file from GitHub Releases. No Python installation or separate dependencies are required.
- **Source code version:** Install Python and Pygame to run the game directly from its Python source file.

To install Pygame, open your terminal and run:

```bash
python -m pip install pygame
```

## Instructions

### Option 1: Download the Executable

1. Open the **Releases** section of this GitHub repository.
2. Download `neon_survivor.exe` from the latest release.
3. Once the download is complete, run the executable to launch the game.
4. Press **START GAME** or hit Enter to begin your survival run!

No additional installations are required.

### Option 2: Run from Source Code

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Install Pygame using the command shown in the Requirements section.
4. Open a terminal in the folder containing `neon_survivor.py`.
5. Run the following command:

```bash
python neon_survivor.py
```

The game will launch, and you'll be ready to enter the arena!

**Note:** Windows may display a security warning when running an unsigned executable. Only run files from sources you trust.

## Controls

- **W / A / S / D** = Move around the arena
- **Arrow keys** = Move around the arena
- **Mouse** = Aim your weapon
- **Hold Left Mouse Button** = Shoot enemies
- **Esc** = Pause or resume the game
- **Enter** = Start the game or resume from the pause menu
- **R** = Restart after game over
- **Drag the window edges** = Adjust the game window size

## Features

- Fast-paced top-down survival gameplay
- Neon-inspired visuals and a futuristic arena
- Enemies that chase the player
- Different enemy sizes and health levels
- Mouse aiming and continuous shooting
- Particle effects when bullets hit enemies
- Health bar, survival timer, and kill counter
- Increasing difficulty as time passes
- Main menu, pause menu, and game-over screen
- Adjustable game window size
